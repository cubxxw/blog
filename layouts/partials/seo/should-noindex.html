{{- /* Single source of truth for "should this page be noindex'd?". Consumed by head.html (robots meta) and the sitemap templates (layouts/sitemap.xml + layouts/sitemapindex.xml, which skip the URL). Rules: - 404 pages - any page with `robotsNoIndex: true` front matter - tag terms not admitted by data/seo/indexable_tags.yml Article count alone is not evidence that a tag page answers a search intent. The allowlist keeps the sitemap focused on editorial topic hubs while all other tag pages remain available for site navigation. */ -}} {{- $unapprovedTag := false -}} {{- if and (eq .Kind "term") (eq .Data.Plural "tags") -}} {{- $tagSlug := .Data.Term | urlize -}} {{- $unapprovedTag = not (isset site.Data.seo.indexable_tags.tags $tagSlug) -}} {{- end -}} {{- return (or (eq .Kind "404") .Params.robotsNoIndex $unapprovedTag) -}}
