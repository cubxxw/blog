# Source Tracing

Use `source_refs` to continue a theme without reading the private target behind `brain://`.

Run:

```bash
npm run briefs:trace -- --file <brief>
```

Read only the related public briefs, receipts, and repository articles. A repeated ref is a connection, not permission to import private material.

Look for three possible continuities:

- **Experience:** recurring events, observations, or decisions explicitly approved for publication;
- **Emotion:** recurring tension, attraction, fear, resistance, or uncertainty explicitly present in public material;
- **Thought:** an earlier claim that the current material extends, contradicts, or leaves open.

Use only the lines that make the current article more alive or more honest. When only a past conclusion exists, do not disguise repetition as a new article.

Record briefly:

```text
related public material
what continues
what changes now
what remains unavailable or unresolved
```
