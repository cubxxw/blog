# 搜索点击优先的 SEO 执行顺序

作者于 2026-11-09 要求后续 SEO 围绕真实搜索点击推进。维护与性能检查继续承担质量保障，搜索增长任务需要交付具体页面的调查、改进和效果观察。

## 每轮先做什么

先检查是否有实际阻断抓取、索引、正文阅读、数据采集或发布的故障。有则修复并保留证据。没有这类故障时，优先读已上线实验，补充 Google 最近抓取时间和到期的搜索结果，再选择一个主要页面推进。观察尚未到期时，记录下次判读条件，继续其他有证据的页面，不为每日任务凑一次修改。

用最新可信的 GSC 数据选择页面。展示 query×page 的真实配对，同时记录页面汇总；两者不能相互替代。先调查有目标查询、有曝光却少点击的页面，核对当前搜索结果、已有正文以及能向读者提供的具体帮助。只有实际收到的查询才是已观察需求；安装、比较等扩展词可以帮助核查意图，不能伪称已有搜索量。

自动提案为空时，查看缺的是查询、页面、索引状态还是明确改法，推进一项有具体对象的调查。现有自动修改门禁保持。需要作者判断的观点或新文章，交付可审阅的具体方案，再按现有授权边界处理。

## 如何验收

每个实验登记目标页面、查询组、搜索采样、内容缺口、修改范围及授权。冻结上线前的完整窗口与来源，记录部署版本、上线时间、最近一次 Google 抓取时间和对照参考页。上线后验证真实 HTML 中的标题、摘要、正文入口与链接，并核对 URL、canonical 和中英文互指。

搜索结果从确认重新抓取后的首个完整 GSC 数据日开始，观察不重叠的28天窗口。报告点击、曝光、点击率及平均位置，按查询组、语言与可获得的设备/国家切片说明变化。初次14天只作观察，不提前宣称实验成立。样本不足则延长，并说明限制。没有重新抓取证据时，保留部署后观测与待确认状态，不把整个窗口当作 Google 已采用新版。

主要结果是目标查询带来的实际搜索点击；点击率帮助解释转化，曝光和位置帮助识别查询构成与可见性变化。总点击增长但目标词没有改善时照实记录，不能借不相关查询宣布成功。参照页只用于背景比较，非随机、低样本实验不作强因果结论。

## 维护如何安排

站内搜索微调、木纹或 GPU 计算、视觉效果、依赖及 CI 维护单独记账，按故障程度安排。若没有证据表明它阻断搜索或阅读，不能挤占搜索增长的主要任务。必要检查按变更风险选择，不为文章修改重复跑全站构建和全量浏览器。

日报首先写搜索结果与本轮主要页面，列明完成的调查或上线、仍待确认的事项及下一次验收条件，再写维护和测试。保持现有免费 CI、凭据与发布门禁；不启用付费服务，不使用无人值守 MiMo Token Plan。
