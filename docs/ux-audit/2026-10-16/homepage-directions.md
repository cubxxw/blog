# 首页表达：两条可见方向，分别验证

此文件保留父任务的设计研究与方案取舍历史。A方向已在E6生产模板落地，短屏在E6.1复验，材质在E6.2继续独立复核；具体证据以batches/source manifest为准，原型不认证生产。原型基线本地checkpoint为 `94e644e5`。

## D0 不变量

访客：第一次从搜索/朋友推荐进入的中文或英文读者；也包括回访找文章的人。张力：需要迅速知道作者在做什么、哪些是可读/可用的真实成果，而不是先理解AI协议或十个社交图标。

应当理解：熊鑫伟把真实AI/工程项目、长期思考和旅途写在这里。应当感到有人在持续写作与实践。第一任务是开始读或看真实产品；想了解作者时再与明确标记的AI分身对话。不可替代的事实来自原文章、真实产品状态、作者照片和旅行书，不新增资历/在线保证。

功能不变量：所有原社交目标可达、首页Bear仍可打开/返回、文章频道/书籍/产品/热力图不删除、根Space仍咖啡、产品意图仍打开products、双语明暗与减少动态效果保留。

## 参考机制（网页内容核验于2026-10-16）

- [swyx](https://swyx.io/)：简明个人身份后以作者选题和真实项目建立内容优先级；采用“精选起点”机制，不复制其视觉身份。
- [Josh W. Comeau](https://www.joshwcomeau.com/)：教程标题、摘要与具体阅读入口直接承载价值，交互来自文章本身；借鉴证明先于装饰。
- [Bruno Simon](https://bruno-simon.com/)：空间探索就是作品机制，并有操作、Unstuck/Reset、音频与设备入口；借鉴清楚控制与可恢复，不能把其驾驶和视觉整体复制给博客。

以上来自网页结构/文字，不宣称完成这些站点的浏览器性能或无障碍审核。

## D1 两个主张

A：**一本公开的实践笔记**。比喻是作者桌上翻开的真实笔记，结构以可读成果为先；标志机制是首屏一篇可直接读的真实文章，AI在阅读起点之后。反参考：匿名SaaS功能卡和装饰数据仪表盘。

B：**先认识一个人，再选择一条路**。比喻是来访者在作者门口聊一句，真实头像和少量具体提问承载个性；主阅读/产品入口仍先于分身。反参考：六颗等权气泡包围头像的协议展示台，以及伪在线客服。

## D2 架构分叉

A1：身份/本期文章并列 → 按真实主题浏览文章 → 旅行书形成视觉停顿 → 产品及相关实践 → 写作记录/联系。AI在文章区之后，可保持原实例与返回路径。

A2：最新文章列表直接成为首屏 → 作者/旅途/项目作为右侧背景注释。优点是回访密度；缺点是首次来访者身份和空间个性可能太弱。暂留A1用于可见比较，不实现A2。

B1：身份与两项任务 → 作者头像/三个真实问题形成一个完整交互 → 文章频道 → 旅行书与真实产品两种不同证明 → 时间记录/联系。

B2：先选“读/做/旅行”再展开对应首页内容。入口更少，但会隐藏现有内容且引入首次分流成本。暂留B1，不增加新的门禁。

## D3 最低保真原型

`homepage-direction.browser.mjs`会保留基线并产生A/B首屏、移动端和中段截图。A/B是浏览器临时DOM/CSS实验，不是已实现或已测试的生产功能。对比后由独立评分角色用相对-2..+2判断主张、清晰度、真实内容、结构差异和风险；不以测试数量换算审美绝对分。

## D4 系统边界

沿用现有纸/墨/酒红与中英主题变量、现有无衬线身份/动作、阅读衬线与真实照片。按钮保留可见focus与44px触控；只主动作实底，其余通过文本、排布和间距分层。社交全部保留，取消十个等权白色盒子的主视觉权重；不新增字体、动图库或假指标。UI/UX资料库的适用结果为触控44px、相邻间距8px、可见focus；检索到的不相关breadcrumb/运营页模式没有采用。

待比较后记录胜者/挑战者与回退条件；当前未选择生产改版。
