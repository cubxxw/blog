本轮按作者要求撤回此前图片咖啡馆，改为可以进入、走动、看四周的三维咖啡馆。当前仅在 `codex/space-cafe-3d-local` 本地开发，预览地址为 `http://localhost:8888/zh/projects/`。没有推送或部署三维版。

## 实现

`world-cafe.js` 使用现有 Three.js r160，真实模型包含木结构房间、桌椅、咖啡机、书架、电脑、键盘、植物、露台及主题景观。禅庭、园林、海岸、山居、湖畔、雨夜书屋改变实际室外几何与照明；游戏不使用全屏背景照片。模型和木材/叶片纹理在浏览器中生成。

开始时镜头在房间外，进入后落到访客视角。WASD / 方向键移动，拖动看四周，点击真实电脑、E 或「走向电脑」靠近桌子。窗口层、Dock、菜单和吸附预览被放进一个 CSS3DObject，和 WebGL 房间使用同一台透视相机。应用继续使用原 DOM 节点与工作区状态；原生搜索和应用弹窗仍在浏览器顶层。离开电脑不销毁笔记、读者或助手。

行走按视角计算方向、归一化对角速度、检查墙体与桌子的碰撞；后台恢复单帧时间受限。自动相机移动遵守减少动态效果设置。手机支持方向按钮与拖动视角，应用入口沿用 OS 菜单和全部应用。窗口拖动与边缘吸附转换悬浮屏幕的显示坐标。

静态房间与重复家具按几何/材质实例化，静态阴影在换景时更新，像素倍率上限为 1.5；本地默认庭院的实际绘制调用约 68。隐藏页面、Product Lab 与后台暂停绘制。退出页面释放事件、观察器、几何、材质、纹理与渲染器。WebGL 上下文丢失会取消镜头、解除禁用按钮并恢复原 DOM 工作区。

## 验证

`scripts/space-world.test.mjs` 的五项验证覆盖相对视角行走、对角速度、家具碰撞与滑动、恢复时间上限、最短角度相机插值和手机/桌面屏幕适配。与现有工作区、场景恢复、语言路由测试一同执行，23 项通过。

`scripts/space-world.browser.mjs` 在隔离 Chromium 上验证真实模型绘制、相机行走/转向、六主题几何变化、物理靠近电脑、CSS3D 屏幕、同一笔记节点保留、语言和重载恢复、手机方向操作与完整应用菜单、模块失败降级、连续镜头及真实 GPU 上下文丢失后的工作区可用性。十组检查通过；桌面与手机截图、回执位于 `output/playwright/space-world/`。手机为浏览器设备模拟，尚未在真实手机上验证。

独立只读审查发现并修复了隐藏 Product Lab 时的初始镜头尺寸、异步入场后窗口聚焦、镜头取消结算与 GPU 丢失后的卡住问题。此前图片版的浏览器回归不代表三维版的验收。

`scripts/space-world-regression.browser.mjs` 另外复现并验证了两项审查问题：隐藏 Product Lab 中的 DOM 脱离页面、助手快捷键后的输入框失焦。两项均先失败，修复后通过；独立审查也再次通过。共享工作区浏览器检查改为从真实搜索快捷键进入电脑，旧咖啡馆 E2E 改为游戏入口与新控制。

最终冻结构建通过；现有 `npm run bear:test` 的 155 项、五项新增行走/相机测试、类型检查与差异格式检查通过。更新后的咖啡馆 E2E 在桌面及手机共八项通过。真实房间测试使用完整 Chromium 的 GPU 渲染，避免 headless shell 软件渲染把输入时序拖成超时。额外修复了初始三维模块尚未载入时重挂载菜单导致的失焦：加载期间界面暂不接收操作，失败或超时恢复工作区；手机悬浮屏幕内按钮扩大，主要按钮实际点击区域至少约 44px。

本轮交付是可玩的本地空间。材质采用简洁的游戏风格；没有制作照片级建筑模型、多人世界、完整物理引擎或实体门店方案。后续发布需作者另行授权。
