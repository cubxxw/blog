# Space companion 会话记录：本地验收

用户反馈助手没有 session 记录，无法查看或继续之前的对话。原来的时钟只展开当前任务栏，任务存储最多保留 12 项；每次模型请求只包含这一次问题，导致「可以」无法接住上一轮的提议。

本轮提供会话历史、搜索、切换、新对话和独立 JSON 导出。已有任务迁入「之前的对话」，旧键保持完整。恢复以前的会话会显示原问答和操作记录，保留未发送草稿；继续提问携带同会话最近三轮问答，并受模型接口文字与条数预算限制。历史不会重新执行工具或继承审批。

## 保存与兼容

`assets/js/space/agent-sessions.mjs` 使用 `space:agent:sessions:v2`，会话元数据、任务、各标签页草稿分别保存成独立行。相互交错的写入不会覆盖整份历史；没有编辑过的旧页面不会把新草稿清空。并行有意修改的草稿版本都保留在 JSON 导出中。

迁移仅在全部记录写成功后保存完成标记，中途遇到配额限制时，下次加载补齐缺失行。兼容原 `bear-agent-tasks:v1` 和早期 session v1 快照，保留有效的选中会话；重复迁移不会重新提权旧草稿。超出 200 万字符预算或浏览器写入失败时明确提示，并保留磁盘已有数据和当前页面的内存副本以供导出，不删旧记录。

同一来源地址、当前浏览器保存。没有跨设备或线上/本地同步；原版本已淘汰的记录无法恢复。刷新后未完成任务显示中断，不自动重放。会话单独导出为 `space-conversations.json`，不属于工作区 JSON。
