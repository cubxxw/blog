# Space 江南夜雨：本地验收

本次把已确认的咖啡馆风格接入 `/projects/` 与 `/zh/projects/`。房间使用专门制作的画幅、可独立绘制的雨雾与风扇，以及投影到屏幕位置的原生按钮。电脑进入现有桌面；平板展示现有公开相片，打开时传递这张照片的 ID。

## 已验证

- `npm run bear:test`：253 项通过，包含新增的 5 项构图、投影、异步切换和销毁检查。
- `npm run typecheck`、`npm run products:check`、`hugo --minify`、`git diff --check`：通过。
- 新房间、原三维场景近景、入场恢复和相片恢复的桌面/手机检查：60 项通过。
- 阅读、产品与书架、原壁纸的定向桌面/手机检查：42 项通过。这个数字与上组有房间测试重叠，不作为互不重复的用例总数。
- 原三维空间的独立浏览器脚本明确选定禅庭后，10 项实际浏览器检查通过，涵盖行走、相机移动、场景、手机、语言切换与图形失败恢复。
- 未指定场景的新浏览器实际打开江南夜雨；正常动态偏好下雨雾与风扇时钟继续推进，未发现页面脚本异常。
- 独立审查复核：中英文各 320×844、390×844、568×320，场景名、行动行、配乐入口均可命中，控件高度至少 44px；行动行与页脚间距为 11–13px。配乐可实际展开。
- 点击电脑、打开笔记、返回房间、再进入电脑：同一个编辑器节点和正文保留。照片平板打开匹配的相片，查看下一张后仍可返回房间。

验证在 `netlify dev` 的实际页面进行；接口与外部内容的合约用例使用仓库现有的固定响应。配乐播放检查确认浏览器在用户点击后开始播放，不代表对听感的主观验收。本记录只描述本地结果，线上发布需再核对部署版本和关键路径。

## 行为与兼容

江南场景成为默认值，场景选择保存到 `space:cafe:theme:v2`。旧版本的偏好值没有删除；新一轮选择会记住用户实际选定的七处场景之一。已有笔记、相册状态和窗口仍由同一桌面管理。

桌面保留完整画幅。手机竖屏可以横向滑动房间，初始位置能点电脑和相片。工作区通过 Dock 的 OS 菜单返回咖啡馆。隐藏页面、安静模式、减弱动态与进入工作区会限制或停止环境绘制；声音默认关闭，通过“声音”按钮开启。

六处原三维场景按需加载。缺少画布、首帧超时和原场景 WebGL 丢失均有普通桌面恢复路径。切换时释放旧场景，不重复注册环境声音按钮或创建编辑器。

## 素材来源

房间主画幅为本次专门制作的想象空间，风扇为想象的旧木器，未引用具体产品或售价。照片使用博客现有的公开旅行相片。

配乐：[Night on the Docks - Sax，Kevin MacLeod](https://incompetech.com/music/royalty-free/index.html?Search=Search&isrc=USUAN1100137)，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)，压缩、调整播放音量并循环播放；页面“配乐”入口保留作者、作品、来源和许可。

雨声：[Rain.ogg，ジダネ](https://commons.wikimedia.org/wiki/File:Rain.ogg)，公有领域。环境声复用已批准样片的雨声处理与本地合成风扇声，混合为可循环的环境轨；不是现场录音。
