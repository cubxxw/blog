# 作者声音本机验收

日期：2026-10-17。范围是本机作者工具、官方 Gemini 适配和静态文章播放器。本记录不表示已经部署上线，也不表示作者个人声音已经创建。

## 已验证

- `npm run voice:test`：15 项通过，0 失败。覆盖共享环境文件只读取 Gemini 密钥、录音格式、个人声音保存、完整文本分段与缓存、取消、失败不重试、文章版本与试听确认、路径限制、元数据兼容和实际 Hugo 渲染。
- `npm run quality:test`：173 项中 172 项通过，0 失败，1 项既有跳过。
- `hugo --destination <temporary-directory> --minify`：Hugo 0.145.0 extended 完整构建通过，英文 344 页、中文 367 页。
- `git diff --check`：通过。
- 对共享密钥执行官方 `GET /v1beta/voices?type=replicated` 与 `GET /v1beta/models/gemini-3.8-flash-tts`，均返回 HTTP 200；当时未列出已保存的个人声音。未用测试录音调用 Google 的声音创建接口。

## 浏览器链路

在隔离目录和模拟供应商下，通过真实浏览器完成参考录音与授权录音上传、本机 WAV 转换、保存个人声音 ID、生成、MP3 试听、确认挂入测试文章、Hugo 构建和静态页面播放。音频使用测试信号，不能用于评价 Google 配音或作者音色。

MP3 实际播放时 `paused=false`，时长 3.048 秒；倍速切换到 1.5 后媒体元素的 `playbackRate=1.5`。刷新没有自动播放，文字稿可展开。人为使测试音频文件不可用后，出现可读的失败提示，文字稿入口保留。390 像素布局下，页面内容宽度等于视口宽度。确认框未勾选时拒绝挂入文章，按钮可以恢复；已加入的记录可再次打开且不会重新生成。

## 尚需作者完成

真实麦克风录制、Google 对真实参考录音与授权的核验、个人声音创建后的相似度与长句表现，均需作者自己的录音和试听。此轮没有新发布真实文章音频，没有把模拟声音当作作者原声，也没有验证生产网站部署。

使用方法见 [作者声音](../author-voice.md)。
