## 已确认的优化点

1. 普通文章页和多数频道页原先都加载 454,969 bytes 的本地 CSS；首页为 252,841 bytes。按页面实际渲染者筛选样式，保持原有顺序，减少无关页面样式。
2. 首页桌面端装饰会在首次空闲时导入 Three.js。加载需要用户交互意图，并继续遵守可见性、节省流量、设备与 reduced-motion 条件；普通聊天保持可用。
3. 首页产品卡片原先直接下载完整 JPG。为卡片生成 480/960/1440w WebP，提供浏览器选图信息、真实尺寸和 JPG 回退。
4. 专属爬虫组原先只有 `Allow: /`，会覆盖通用组的路径限制。各组必须保留 `/admin/`、`/private/` 限制，非生产环境不放开抓取。该规则是抓取政策，不代替访问控制。[Google robots 分组说明](https://developers.google.com/crawling/docs/robots-txt/robots-txt-spec)
5. 最新远端已部署独立生成的 OG/Twitter 卡片，提供真实尺寸，初始旧代码中分享图片的尺寸问题已经解决。本轮保留该流程，修正 BlogPosting 相对路径封面的公开 URL，并为 SVG 封面使用现有分享卡片兜底；移除没有真实查询入口的 SearchAction。[Google Article 结构化数据说明](https://developers.google.com/search/docs/appearance/structured-data/article)

缩减渲染所需 CSS 与使用响应式图片遵循 [LCP 优化指南](https://web.dev/articles/optimize-lcp) 和 [响应式图片指南](https://web.dev/articles/serve-responsive-images)。

## 验证与复现

Hugo 版本：`0.145.0+extended`。构建固定 `--environment production --clock 2026-10-12T12:00:00+08:00 --minify`，前后使用相同设置。

最终本地验收：

- 生产构建与 development 预览构建通过；预览首页为 `noindex, nofollow`，全部 29 个爬虫组禁止抓取。

- 现有分享图片测试 5/5 通过；保持中英文首页和 About 的品牌卡片与文章标题卡片。
- 浏览器验收 53 项通过、11 项按 viewport 适用性跳过；覆盖中英文首页、聊天流与重试、首次交互装饰、减少动态效果、节省流量、手机、搜索、主题、语言切换、响应式缩略图、频道/专栏明暗布局和文章目录导航。

- 全站 SEO 输出检查通过：593 个 canonical HTML、435 条 sitemap URL、50 个 alias 和 289 个精确内部重定向。
- 独立 review 确认缩略图清晰度与专栏底部导航两项发现已关闭，未留下确认问题；`git diff --check` 通过。

新增 `npm run performance:check`，并在 CI 的冻结产物构建后运行。测试兼容 Netlify 内联 critical CSS 和延迟加载的原始样式。可用 `SITE_OUTPUT_DIR=<生产输出> SITE_PREVIEW_DIR=<预览输出> npm run performance:check` 重现本地完整检查；不提供预览目录时只跳过预览专属检查。

以上构建未重复本地全站视觉截图与全部 E2E。线上 PageSpeed 和真实用户性能应在部署后独立采集，本报告不宣称搜索排名提升或重写历史样本。
