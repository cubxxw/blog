# 思考笔记与阅读对话的呈现

月度归档里的 `.note-block` 是原始随笔的阅读单元。正文使用站点现有系统黑体，字号 17px、行高 1.78；标题 18px，手机端 17px。时间与标签使用较轻的 12px 字号。中性文字颜色和纸张底色分别适配明暗主题，规则只作用于笔记块，普通长文继续使用原有排版。原文与 memo 来源标记保持不变。

分享图以回答正文为主，提问放在回答下方的轻引用中。页脚给出文章出处与二维码，保留 AI 阅读札记标识，日期只使用已有文章或调用方明确提供的日期。当前回答和全部对话均可导出；预览保持可读宽度，长图通过滚动查看。导出宽度 1080px，高度随内容变化，极端输入在 14000px 内明确标注为 AI 对话节选。复制文字保留所选内容的完整段落，二维码只链接原文。二维码缺失或不可编码时不显示扫码邀请。

文章阅读接口使用中英文普通自然段提示词。模型需直接回应问题，区分原文与推测，不编造引文、数字或链接；参考资料作为单独的数据消息传递。桌面与手机均将回复作为转义后的普通段落呈现，保留段落、数字与代码内容。延伸阅读链接由界面提供，书籍追问所需的内部 JSON 继续保留。

相关定向检查已注册到 CI 的 functions 检查组：

```bash
node --test scripts/article-ai.test.mjs scripts/share-conversation.test.mjs scripts/reading-reply.test.mjs
```

模板或样式修改后，使用 `netlify dev` 检查中英文笔记、普通文章、桌面、手机与深色模式，并运行 Hugo 生产构建。分享图还需查看实际 PNG、长回答末段、提问与页脚顺序，并解码二维码核对目标地址。模型的真实表达质量需通过实际对话观察；接口测试验证提示词和数据传递，界面测试使用固定回复。
