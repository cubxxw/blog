# BEAR OS：个人工作区设计

用户已经选定「个人电脑」方向，并明确要求同步远程、实现和本地测试。本次在现有 `/projects/` BEAR OS 入口实现工作区，不重写文章系统；Product Lab 保持双向切换。

## 体验

进入即是桌面，无强制开机动画。独立窗口支持打开、聚焦、移动、边缘吸附与并排、最小化、最大化和恢复。Dock 显示正在运行的应用；工作区概览用于切换窗口。手机使用全屏应用与应用切换，不把桌面缩小塞进手机。

初始展示作者欢迎页和一张公开旅行照片。应用包括产品、阅读、照片、地图、书架、访客笔记、联系与留言、终端、Agent 和设置。产品、文章、书籍、个人介绍与社交链接全部来自仓库真实数据。照片使用已经公开的旅行图片；地图明确标注当前公开地点，尚未连接 Immich。

图片、地图、阅读与产品能通过同一操作接口相互打开。阅读器取得站内真实正文，保留原文链接。访客笔记可编辑、导出，刷新后保留。留言采用草稿和真实发布渠道，不虚构已发送状态。AI 接入已有 blog-ai，失败、未配置与取消可见；本地命令能真实操作桌面，不冒充 Linux shell。

## 模块边界

`assets/js/space/state.mjs`：窗口状态、布局、版本化本地持久化、数据边界。
`assets/js/space/apps.js`：真实目录、内容阅读、照片地图、编辑、联系和 AI。
`assets/js/space/desktop.js`：桌面、手势、快捷键、搜索、概览、Dock、视图切换。
`layouts/partials/space/desktop.html`：可访问的桌面和构建时公开目录。
`assets/css/space.css`：页面独立样式。

图形界面、CLI 和 Agent 操作入口共用 `execute(name, args)`，操作包括打开、关闭、移动/排列窗口、搜索、写笔记、导出。本地工作区使用 localStorage，空间导出包含用户笔记、布局和收藏，不包含密钥。不运行模型生成的 JavaScript，不开放浏览器访客到宿主 shell。

真实个人电脑的后续服务分为长期空间数据、任务控制服务、Agent 执行进程和按需沙盒。本地已实现 Docker 执行服务：只绑定回环地址，使用独立容器和持久卷；网页与 AI 向导通过同一个 `run` 工具调用。生产环境拒绝该执行入口。服务端登录、跨设备同步和 Immich 凭据尚无部署配置，本版显示实际可用范围，禁止模拟登录或模拟任务完成。接入这些服务独立于桌面模块，不需要替换博客。

## 视觉

原创山水晨光壁纸，温暖浅色应用、明确层次、克制的玻璃工具栏。采用真实作者照片，避免借用 macOS 商标或复制参考网站素材。所有控件反馈即时，手势逐帧跟手，拖动期间无位置过渡。减少动态效果、键盘和触摸均可使用。
