## 已实现

- **咖啡**：有内外壁、薄杯沿、杯底、弯柄与凹碟；液面位于杯沿下，主杯显示细叶 rosetta 拉花。杯碟按真实桌面高度接触，咖啡机上的备用杯保留为空杯。拉花为生成纹理，风格参考比赛作品，没有真实获奖声明；[资产来源](latte-asset.json)。
- **书架**：沿用现有 `data/travel.yml` 的十本真实书目，四本自著封面、六本旅行书脊，加入纸页／封面厚度、书挡和实体后托。中文、英文标题均可近看；六本没有原网址的书未编造链接，原 Books 应用的数据未替换。
- **物件关系**：圆桌增加窄倒角、连续木纹；纠正面朝桌外的双椅，默认视角改为站在桌边看主杯和桌上书；保留电脑、猫、工作区与双视图切换。
- **窗外**：枫叶改为厘米尺度的透明叶片，连接不同高度的渐细枝条并形成重叠冠层；苔地改为水平低伏、按地面高度接触。叶卡固定预算 64,990 张，没有额外持续树叶动画。
- **边界状态**：新增近景保持原相机与焦点；纹理缺失仍能进入场景，WebGL 丢失返回可用工作区；仅 BEAR 根页面隐藏强制滚动槽，Product Lab 可正常滚动。
