# 雨夜咖啡馆：实物交互与连续听音

本轮按作者确认的整体效果图和左侧近景，把设计接入现有 Space。范围为本地工作区，保持 BEAR OS 与 Product Lab 两个入口，保留原生电脑节点、笔记、选区和照片目录。正式站点尚未发布此轮改动。

## 设计与使用方式

左侧用低柜、开放书格、咖啡台和上方木架形成一组；唱机在手可及的台面，号角以独立音箱立柜呈现，唱片封套可以挑选。玻璃木壳摆钟、小范围的层板灯与花瓶照明延续参考图。木纹、窗樘、纸面与桌面仍使用上一轮经过比较的材质。

交互采用物件本身作为入口。桌灯、层板照明、风扇点击后改变真实灯源或机械状态；咖啡机有可取消的八秒萃取，唱片只在音乐播放时转动，摆锤随房间时间轻摆。书籍逐本可读标题、作者和已有简介；自著书保留真实阅读地址。桌上的笔记本打开同一个 Notes，椅子和电脑进入原生工作区，相框保留实际照片目录。

近景没有外部“返回”按钮。点击关注物体以外的空间、在外围滚轮拉远、双指收拢、Esc 均可回到原来的相机位置。详情自身滚动不触发退出。电脑的屏幕外也可点击回到房间，屏幕内部继续使用原生窗口与输入方式。键盘进入物体近景时焦点移到其标题；Tab 可访问物件、书籍与唱片，焦点导航只在使用键盘时出现。

## 声音和站内阅读

雨声沿用上一轮独立的 100 秒采样时钟循环。三首唱片是三段不同的真实录音：Kevin MacLeod 的 Night on the Docks - Sax、Long Stroll、Almost New。封套复用作者公开旅行照片，曲目不冒用这些照片的拍摄故事。官方曲目、许可、下载出处、校验和加工分别记于 `static/audio/space/*.json`，署名可从电脑“帮助”查看。

换片只替换音乐通道；雨声的节点和进度保留。音乐启停渐变、失败恢复、旧加载不能覆盖新选择、解码缓冲释放均有定向检查。

同一标签页从空间打开站内公开 HTML 页面时，原文档和 AudioContext 保持连接，阅读内容进入同源的独立浏览上下文。网页保留自己的脚本、导航、搜索、筛选与滚动；外层地址、标题与历史同步。返回时保留同一个 iframe，避免删除子页面原生历史导致前进记录丢失。空间在阅读时暂停三维绘制，声音不暂停。江南场景另启用后台播放选项，页面收到后台可见性通知时不主动暂停音源；主动暂停、安静模式、隐藏房间和销毁仍保持原行为。后台通知测试保留真实音频节点，但不等于已经验证所有设备的后台播放政策。

修正了搜索弹层的 Escape 优先级，先让文章关闭自己的搜索，再允许下一次 Escape 返回空间。搜索的程序化跳转、普通链接、筛选 replaceState、后退与前进分别验证。外站、下载、带修饰键、新标签页和直接刷新保持正常浏览器行为；连续播放的承诺限于这次会话内同一标签页的站内浏览。

为支持同源阅读，`netlify.toml` 的 `X-Frame-Options` 从 `DENY` 改为 `SAMEORIGIN`，仍拒绝其他来源嵌入。本地 Netlify 服务需重启才会采用新响应头，已核对实际响应。Hugo 开发入口使用 `--baseURL http://localhost:3987 --appendPort=false`，避免绝对导航指向内部的 1398 端口。此为本地配置验证，未表示已部署。

## 猫咪的实际边界

新增江南房间专用的路线与碰撞适配。猫可以走动、停留、转头、眨眼和回应抚摸；桌椅、矮柜、号角均纳入避让。房间隐藏、安静模式与减少动态效果时不推进动作。猫的时间使用每帧增量，避免把累计时间作为增量导致过快移动；重复抚摸使用真实经过的冷却时间。装饰胡须不参与实体拾取，避免一米宽的线段拾取容差抢走桌灯点击。

**当前猫模型仍偏卡通，尚未达到作者要求的写实程度。** 调整材质、比例和步态并不能把这个来源变成真实扫描。已核查几个候选模型；需要登录下载、缺少资产许可或实际仍为玩具造型的素材没有替换进产品。具体来源、拒绝原因和实际渲染见 `static/models/space/CAT-JIANGNAN.md`。不以“95 分”给这项未解决的问题作结论。

## 迭代验收

用户要求的 95 分作为打磨目标，未换成自评分。每轮分别记录功能事实、图像比较和未达到的审美要求。实际浏览器检查包括桌面与手机的灯光、风扇、点击外围、缩小退出、电脑节点保留、逐本书籍、唱片替换与雨声身份、猫回应与时间、站内页面和原生历史；静态渲染检查与真实交互分开。

第一组原生测试先暴露缺少开关入口，再验证实际灯源变化。后续真实浏览器又发现猫回应被取消、冷却时间不结束、胡须误拾取、猫时钟过快、阅读搜索的 Esc 优先级以及程序化跳转的前进记录丢失；逐项补回归并修正。原物件流程还发现电脑的打开点击会被外围退出误消费，已增加一次性动作归属保护，真实电脑与照片流程重新通过。

最终结果：`npm run bear:test` 358/358；类型检查、中英文 Products 集成检查、本地 Hugo 生产构建通过。四个原有浏览器文件 58/58；新增生活空间文件的桌面/手机操作 18/18，另补后台可见性通知 2/2，共 78 项不同浏览器用例通过。猫初始位置移到柜边，避免开场只截到半个身体，随后定向复验四项猫咪原生用例通过。独立审查者复验关闭五项 P2，最后尾部审查未发现新增 P1/P2；此结论不替代猫咪写实程度的审美验收。

主视角比较过正面与两个侧面方案，选择能同时看见低柜、听音角、摆钟和完整电脑的侧面。三维房间仍可自由转向风扇。固定相机比较图在 `.netlify/cafe-lab/image-living-v2-*.png`；未替换模块的实际桌面、手机截图在 `living-live-*.png`，结构化结果在 `living-browser-check.json`。两种视口均加载真实材质与环境资源，雨声在播放、音乐默认关闭，外部导航不可见，没有横向溢出、页面或着色器错误。家具实际资源释放 811/811，书格暖灯、单头咖啡机与萃取落点另有几何/射线定向检查。

站内历史连续性原生证据保留于 `output/playwright/space-history-native-after.txt` 与 `space-history-native-filter-links.txt`；原来的失败记录亦保留。对比页位于 <http://localhost:3991/?iteration=living-v2>，本地空间位于 <http://localhost:3987/zh/projects/?vista=image&iteration=living-v2>。未提交、推送或部署此轮改动；原始主工作区只保留其已有 `output/`，实现位于附加 worktree。
