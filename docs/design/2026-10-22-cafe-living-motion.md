# 水面、游船、呼吸与镜头衔接

本轮继续在 `codex/space-night-cafe` 本地工作树打磨现有咖啡馆。依据实际源码、前后画面和连续操作检查处理动态细节，沿用原场景、工作区与声音，不修改线上发布状态。

## 前后变化

| 观察 | 上一版 | 本轮 |
| --- | --- | --- |
| 湖面 | 静态照片占主要画面，叠加波纹偏弱 | 只在纯水域折动倒影，增加细波亮部、雨滴涟漪与缓慢起伏；岸、桥、建筑保持注册 |
| 船 | 135 秒横穿后循环复位，船身始终横着 | 每次进入选一个稳定种子，在有边界的湖面上作连续的左右、远近游动；船头与船尾水迹随航向转动 |
| 云 | 运动偏弱，云的时钟还混入了房间日期 | 不同尺度的云层缓慢漂移和聚合，使用同一个可暂停的环境时间；调魔法时钟不会使云突然换位置 |
| 睡猫 | 很小的对称起伏，观察物品时会冻结 | 胸部先吸气，腹部略滞后，呼气更长；呼吸与行为分开计时，观察书架或在电脑前停留时仍呼吸，保持原睡姿与位置 |
| 接近物品 | 直线或折线，固定时长，边转边拐容易生硬 | 同一条圆滑的避障路线，按距离和转角调整时长，缓起缓停；相同机位不重复播放接近动作 |
| 中途退出 | 位置连续但速度归零 | 从当前真实姿态、位移与转动速度接续，先消解动量再返程；仍用外围点击、滚轮、Escape 与原有手势退出 |
| 横竖屏切换 | 移动目标与已创建的动画可能不一致 | 重建剩余路径，保留同一个完成回调；窗边和电脑机位都不会等到终点才突然换镜头 |

物品说明在镜头稳定后轻轻显现。移动途中不做昂贵的悬停射线检测，静止悬停也限制频率；拖动会直接接管镜头，轻点不误停动画。没有增加房间导航或返回按钮。

低帧率复测还发现旧模拟步长会拉长接近和退出时间。相机现在拥有独立的可见时间基准，物理仍用有上限的步长。新建或改向不会继承点击前的帧间时间，进入后台后保留原进度，回来也不会追赶隐藏的时间。

## 运动与边界

船的轨迹在 XZ 两轴上连续求值，不能逐帧重新随机。半小时采样检查覆盖双轴方向、边界、航向和循环连续性。照片模式仍对船的实际位移比例修正航向，水迹按相同方向计算。

水纹只作用于实测的纯水带，避免把整张照片当壁纸滑动。云、水、船和猫均沿用房间的渲染生命周期。减少动态效果或安静模式下，环境运动暂停，主动导航仍可立即完成；没有增加定时器或独立渲染循环。

相机按路径距离参数化，拐角保留额外家具间距。中途反向的残余动量先在构造阶段预采样，以缩短固定衰减时间控制足迹。每帧临时将位置减半会造成跳变，已通过失败用例复现并移除。独立复核中，原家具旁回归的最大半毫秒位移从 13.660 毫米降至 1.179 毫米，碰撞样本为零；这属于数值检查，不等同于真人评价。

## 验证与证据

原始文件快照在 `output/living-motion/` 的 `*-before` 文件中。红用例记录包括原单向循环、睡猫静止、相机拐角、速度突停、旋转速度叠加、家具旁位置跳变及中途 resize 的 8.995° 终点跳变。没有删除失败记录。

镜头最后计时修正前，全套逻辑检查通过 439 项；修正后的运动、窗边、真实猫骨架、场景和材质生命周期定向检查通过 40 项。类型检查、生产构建和差异检查通过。桌面、手机合计 8 个独立场景复核通过，记录见同目录的 `delivery-results/` 与 `resize-delivery-results/`。浏览器操作使用实际页面和真实指针，日间水域和云层另以固定机位前后像素变化验证，避免把下雨或镜头移动误算为水面在动。

浏览器测试的中途拖动以真正接管后的姿态是否持续稳定验收，不把自动化指针到达前的正常镜头移动误判为跳变；横竖屏的末段角速度按与镜头相同的动画帧时间戳衡量，避免把渲染耗时波动误算为终点跳跃。最后的 resize 两项重跑均通过；早先以回调执行时刻估算帧间隔的失败记录保留。几何、初速度和终点连续性另有独立数值测试。
