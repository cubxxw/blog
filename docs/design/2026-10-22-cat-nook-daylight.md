# 窗下猫窝与昼夜

本轮承接已确认的猫窝概念图。移除左侧阅读扶手椅，保留电脑前的工作椅。猫窝在纸窗下、书柜与书桌之间，采用低矮胡桃木托盘、亚麻软垫和驼色毛毯。人不能走进猫窝，猫可以走上软垫；落脚高度来自实际软垫曲面。

白猫默认睡在窝里，呼吸、闭眼。轻点猫或猫窝后，先用 2.6 秒醒来，再沿安全路径走近。到达后再次轻点可以抚摸，稍作停留后自行回窝。减少动态效果开启时，只回应和看向访客，不强制移动。睡姿是现有骨骼的新编排，仍是风格化模型，毛发与解剖真实度未达到写实动物资产的程度。

按作者明确选择，现实 144 分钟对应小屋一天。首访从 21:00 开始；时间起点保存在本地，刷新、切换页面和后台停留后继续同一昼夜。摆钟指针、天色、降雨、雨声和猫咪作息读取同一时间。雨滴、摆锤和猫咪动作保留正常速度。清晨逐渐停雨，07:00 至 18:30 无雨，夜间恢复；音乐声道独立。

白天景色由夜景原图生成对应的晴天素材。桥、建筑、树木与山体沿用原有构图，白天关闭灯笼光和橙色水面反射。窗边观察点改为书桌左侧，抬高白天视线，使太阳能从实际窗洞中露出。晴天素材加载失败时保留可照亮的几何外景。

正常入口为 `http://localhost:3987/zh/projects/?vista=image&iteration=cat-nook`。本地快速比较可以使用 `room-hour=10` 或 `room-hour=21`；该起始时间覆盖只对 localhost / 127.0.0.1 生效，不写入持久时间。页面没有增加时间控制栏。

实际页面截图保存在 `output/cat-nook/night.png`、`day.png` 和 `day-window.png`。来源与哈希记录在 `assets/images/space-cafe/jiangnan-vista-day-v1.provenance.json`。

验证记录：定向状态、真实骨骼、几何、音频和资源生命周期检查 162 项通过；生产构建与类型检查通过。浏览器中已实际轻点猫咪并读回到达状态，检查白天雨声暂停、窗边太阳及控制台。审查修复后的最终桌面、手机页面回归共 30 项通过，包含阅读途中跨过清晨、醒来途中切换减少动态效果、电脑内部操作和跨页连续播放。验收回执为 `output/cat-nook/receipt.json`。

独立审查找出的三项问题均已修复：回窝途中再次呼唤会清除旧路径；切换安静或减少动态效果时终止旧互动；天气有单独持有和销毁的每秒唤醒，读文章期间照常调整雨声，可见静态页面仅重绘一次而不恢复物件动画。审查者独立复跑 84 项检查、110 组中途再次呼唤场景，通过后确认本轮范围无剩余已证实问题。
