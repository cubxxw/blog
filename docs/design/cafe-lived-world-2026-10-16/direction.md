# 有人生活的咖啡书房：整体验收合同

基线 `75e82d56`。2026-10-16 新的人类主动反馈继续授权实现，不恢复旧 12:00 heartbeat，不把上一轮局部通过当作整体审美通过。唯一源码工作树不变。沿用 frontend-design、deepen-design 的“先场所与行为，再材料微调”原则；不调用 brainstorming 审批或付费模型后端。

## 场所与两种解释

访客来到作者的咖啡书房：在桌边看到刚喝的咖啡与在读书，能顺着窗光找到植物与远景，看到住在这里的猫，并可以和它互动、继续进入原工作区。它应有日常使用的因果关系，不成为堆道具的展示厅。

候选 A 是“作者日常使用的林间咖啡书房”：在读书、笔记、原旅行照片、咖啡工具和猫有各自可用的位置；桌边→猫→工作桌→露台构成体验。候选 B 是“完整经营中的商业咖啡馆”：点单墙、服务台和客席成为主线。用户没有授权编造营业／菜单／奖状等商业事实，且 B 会挤走个人博客与原工作区，因此选 A。保留 B 仅作场所叙事对照，不把它实现成假商店。

上一轮人眼／微缩构图 A/B 已保存在旧目录：保留人眼站在桌边，拒绝回退到微缩俯瞰模型。新比较重点是相同相机的整室、工作角与露台，而非再次更换一处杯子。

## 材料与光线约定

明暗由窗外冷日光、室内暖灯和遮挡解释。灰泥 `#d9d3c7`、木材保留摄影纹理本色、炭色金属 `#282c29`、植物深绿 `#3f5939`、灯芯暖白 `#ffe4b0` 仅是校准方向，不能用统一棕黄色滤镜覆盖全部表面。现有 UI 字体与终端风格保留，14px 普通动作文本、44px 命中和清楚焦点。UI 不抢世界主体，手机不能出现重叠动作。

摄影材质采用 Poly Haven 的 CC0 本地资产，源与 hash 见 material-assets.json；颜色图 sRGB，normal／roughness 为数据图，尺度按米考虑。铝／陶瓷／木材／灰泥／布各自的反应不能相同。1k albedo、512 normal／roughness，另 1k HDR；不增加远程运行依赖。官方 Three r160 RGBELoader 与现有版本一致，来源见 rgbe-provenance.json。纹理／HDR失败保持可用回退，dispose 后迟到只能释放，不再写 root 或 wake。

## 预先固定的整体验收门槛

1. **全景成立**：同位置 1440 与 390 对比默认室内，另看工作桌、墙体和露台；窗光、木材、植物、岩石远山在同一画面中改善，不能只用咖啡特写证明整体。
2. **光线有因果**：桌沿、椅腿、墙脚、杯碟有接触；减少大块硬黑或洗白色块，吊灯照到可解释的表面；zen 与 rain 的室内／外景明暗相符。静止阴影不游动，不为静态材质增加持续循环。
3. **材料有尺度**：近桌、桌腿、梁、地板和墙的纹理没有随盒体缩放拉长；各通道正确，石、木、灰泥不共享同一噪声；近看与远看都不靠高对比旧化成立。
4. **建造与使用成立**：墙脚、窗框、架板／桌沿有可解释的厚度和接缝。生活细节只选符合现有作者内容的两三组，落在实际表面、留出通道，不编造营业信息或奖项。
5. **植物长在一起**：室内盆口／土／叶柄／薄叶相接；枫树冠体保留疏密，松与海岸树不能继续套用星形枫叶；不以加叶数量或风动掩盖结构。
6. **岩石与远山有体量**：近中远石群有非对称轮廓和埋地重量；苔边界不再是规整绿枕；山居／湖畔／zen 的峰线与层次不呈相同平面卡片重复，近脊横移有视差。
7. **猫可发现、可回应**：原生按钮、键盘、手机触摸和实际猫命中进入同一动作；近景可看清眼神／头尾反馈并回原 pose／触发焦点。普通模式有限叫来走可达路径；reduce／quiet 仍有立即可见的用户触发响应，不强开自主漫游。拖动与遮挡命中不能被破坏。
8. **连续性与回退**：六景切换、工作区双向切换保留原 DOM；资产失败／WebGL 失败仍可工作。保持减少动效、quiet、后台、隐藏和 dispose 边界。不读写私人笔记、不真实发模型请求。
