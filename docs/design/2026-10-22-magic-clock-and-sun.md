# 魔法时钟、日出与落日

本轮在原有小屋里增加可回拨的时钟。点击墙上摆钟后，视角留出整扇窗，左下出现圆形刻度。鼠标、触屏和方向键都可以调时间；按住刻度时暂停所借来的时间，松手继续以现实的十倍推进。中央“此刻”回到始终流动的自然时间。返程可以重新抓住，点击外围或按 Escape 退出，不增加房间导航栏。

原有自然时间起点保持不变，借来的时间单独保存偏移。刷新后可以继续上次所选时刻。页面进入后台或文章阅读时，天气继续读取同一时钟；“回到此刻”也能完成，不依赖房间持续渲染。

白天底图去掉了固定的太阳和水面高光。太阳沿窗前的设计弧线从左侧升起、在右侧落下，山脊负责遮挡日轮。天空先亮，太阳再露出；云层按连续噪声漂移和聚合。落日前，低角度光线变暖，水面上的闪光带更强，并随太阳横向移动。暮色结束后才恢复夜雨。夜间保留原有连续雨声与远处雷暴录音，云内偶尔有远光；减少动态效果时关闭闪光。

猫咪采用同一个真实骨架与网格，睡姿收成 C 形。头落到前爪附近，尾巴绕回身体，胸腹通过姿态修正减轻硬折痕。醒来逐步展开，再进入原有走路与抚摸流程。原始模型文件未改变，视觉仍保留低模风格。

两项重点审查问题已处理：键盘打开时焦点直接进入刻度，退出后回到可见画布；手指按下即中断返程，避免按住时仍转动、微动后跳回。点击“此刻”后立即离开页面，也不会把返程停在半路。

本地正常入口为 `http://localhost:3987/zh/projects/?vista=image&iteration=magic-clock`。`room-hour` 仅供本地预览设定起始时刻，不写入持久时间。验证结果和实际截图保留在 `output/magic-clock/`；本轮未发布到线上。
