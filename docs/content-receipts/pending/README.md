# Pending content receipts

These blog-side receipts distinguish a published article from observed reader outcomes. `publication_status: published` records the verified production publication. `status: pending` remains until real reader feedback is available and recorded; an automated browser check cannot supply that feedback.

The three 2026-10-23 product receipts include both canonical URLs, the actual Netlify publication timestamp, the immutable deployment source, and verification evidence. Regression fields preserve their actual state. Upstream import is separately pending until its destination is accessible and read back.
